# Popover

A Radix popover (`ui/popover.tsx`): a 288px `popover` panel with `border`, `radius-md`, 16px padding and a medium shadow.

- **Use** for a short explanation or a small form attached to a control, like "How is SSC worked out?". For a one-line hint use `Tooltip`.
- **Consumer provides:** `Popover` > `PopoverTrigger` + `PopoverContent` (`align`, `sideOffset`, default 4).
