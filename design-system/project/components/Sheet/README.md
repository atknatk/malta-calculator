# Sheet

A side panel built on Radix Dialog (`ui/sheet.tsx`) that slides in from `top`, `right` (default), `bottom` or `left`, with a black 80% overlay.

- **Use** for the mobile navigation menu and longer secondary forms that shouldn't leave the page.
- **Consumer provides:** `Sheet` > `SheetTrigger` + `SheetContent` (`side`), with `SheetHeader` (`SheetTitle`, `SheetDescription`) and an optional `SheetFooter`.
