# Card

The base surface from `ui/card.tsx`: `card` fill, `border` hairline, `radius` (12px) and `shadow-sm`, with Header, Title, Description, Content and Footer parts.

- **Use** for dashboard panels, result blocks and settings groups. For links to calculators on marketing pages, use `CalculatorCard`.
- **Consumer provides:** the parts as children. `CardTitle` is 24px semibold and tight, `CardDescription` 14px `muted-foreground`, and every part pads 24px.
