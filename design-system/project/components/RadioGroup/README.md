# RadioGroup

A Radix radio group (`ui/radio-group.tsx`): 16px circles with a `primary` border and a 10px `primary` dot, stacked with an 8px gap.

- **Use** for mutually exclusive choices with longer labels or more than four options. For 2–4 short options inside calculators, use `PremiumToggleGroup`.
- **Consumer provides:** `value`, `onValueChange`, and `RadioGroupItem`s, each with a `Label`.
