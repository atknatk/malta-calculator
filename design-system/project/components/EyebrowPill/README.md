# EyebrowPill

The small glass pill above hero headlines: a Sparkles icon and a 14px medium claim in `primary` on `glass-bg`, with a `primary` 20% border and `radius-full`.

- **Use** once per hero, for one short claim in Title Case.
- **Consumer provides:** the text and an optional 16px Lucide icon. In the codebase it's inline markup in `marketing/hero.tsx`, not a component (an intentional addition here, so the pattern is reusable).
