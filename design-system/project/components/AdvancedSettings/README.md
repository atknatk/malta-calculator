# AdvancedSettings

The collapsible "Advanced Settings" bar from `salary/form-primitives.tsx`: a `radius-2xl` bar with a soft gold-to-blue wash and a settings icon tile. Its panel opens with a 0.3s height and opacity animation (framer-motion).

- **Use** under the main calculator fields for optional inputs such as fringe benefits, allowances or birth year.
- **Consumer provides:** `isOpen`, `onToggle` and `children` (fields). The label is fixed as "Advanced Settings".
